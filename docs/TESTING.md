## Manual tests with real models

Start Ollama, backend, and frontend first (see README).

### 1. Health check

PowerShell: `Invoke-RestMethod http://127.0.0.1:3001/api/health`
Expected: `ollama: True` and your three model names in `models`. In the browser, the badge says "Local AI available".

### 2. Question answering

Click **Load sample**, ask "What is a partial dependency?". Expected: an answer based on the notes and the model name under "Generated by".
Then ask "Who won the 2011 cricket World Cup?". Expected: the answer says this is not covered in the notes (small models may not always comply; note what happens).

### 3. Summarization

Click **Summarize notes**. Expected: the five headings (Main idea, Important concepts, Key definitions, Important facts or relationships, Revision points).

### 4. Quiz generation

Click **Generate 5-question quiz**. Expected: 5 questions, options A-D, "Correct answer", "Explanation". Small models may deviate; record which models follow the format.

### 5. Invalid input

- Click **Ask** with empty notes: friendly message.
- Ask with an empty question: friendly message.
- Upload a `.pdf`: "Only plain-text (.txt) files are supported".
- Upload a `.txt` over 12,000 characters: size message.
- API test with a bad model (PowerShell):

```powershell
$b = @{ action="ask"; notes="x"; question="y"; model="not-a-model" } | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:3001/api/study -ContentType "application/json" -Body $b
```

Expected: HTTP 400 `INVALID_MODEL`.

### 6. Unavailable model

If one of the three models is not installed, selecting it shows "(not installed)", and running it shows an error mentioning `ollama list`. Nothing is downloaded.

### 7. Ollama unavailable

Quit Ollama from the system tray, click **Retry** in the header. Expected: red badge "Local AI unavailable" and a banner explaining how to start Ollama. Restart Ollama and click Retry.

### 8. Backend unavailable

Close the backend window and refresh the page. Expected: red badge and "Cannot reach the backend" message.

### 9. Offline verification

1. Complete setup while online.
2. Start Ollama, backend, frontend.
3. Disconnect Wi-Fi/Ethernet.
4. Open `http://localhost:5173`, check the badge.
5. Load sample notes, ask a question, summarize, generate a quiz.
6. In DevTools (F12) -> Network, confirm all requests go to `localhost`/`127.0.0.1`.

### 10. Browser checks

- Resize to about 390 px wide: no horizontal scrolling.
- Tab through the page: every control reachable, visible focus ring.
- Press Enter in the question box: submits.
- Click **Copy response**, paste in Notepad.
- Click **Cancel** while loading: the request stops and buttons re-enable.
- DevTools console: no red errors.
