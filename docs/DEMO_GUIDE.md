# Two-minute demo guide

**Before you go on stage:** start Ollama, backend, and frontend; open `http://localhost:5173`; confirm the green badge; warm up the model by asking one question beforehand (the first request after launch is usually slower). Keep `sample-data/dbms-notes.txt` ready. Consider disconnecting Wi-Fi to show that it works offline, but only if you have tested it.

## Script

**0:00 - The problem (15 s)**
"Students have pages of notes and little time to revise. Cloud AI tools can help, but they send your notes to someone else's server and need internet."

**0:15 - The app (15 s)**
"This is AI Study Buddy. It turns your own notes into answers, summaries, and practice quizzes, and everything runs on this laptop."

**0:30 - The model (15 s)**
"It uses open-weight models through Ollama. Here I can choose between qwen3:4b, qwen2.5-coder:1.5b, and gemma4:e2b. The badge shows that the local AI service is running."

**0:45 - Live demo (50 s)**
1. Upload `dbms-notes.txt` (or click Load sample).
2. Ask: "What is a partial dependency?" Point out the "Generated by" model name.
3. Ask something not in the notes. Point out how it says so.
4. Click **Summarize notes**, then **Generate 5-question quiz**. Show the answer key and click **Copy response**.

**1:35 - Why local matters (10 s)**
"Notes stay on the device, it works without internet after setup, there are no API costs, and no account."

**1:45 - Limitations (10 s)**
"Text files only for now, notes are limited to 12,000 characters, small models can make mistakes, and responses can take a while on a laptop."

**1:55 - What's next (5 s)**
"Next: interactive scored quizzes, PDF support, and retrieval for large note collections. It is open source, so contributions are welcome."

## Tips

- If the model is slow, say so honestly; use `qwen2.5-coder:1.5b` for a quicker demo.
- If a quiz comes back in a slightly different format, that is a known limitation of small models. Click the button again.
- Do not quote speed, accuracy, or user numbers unless you measured them.
